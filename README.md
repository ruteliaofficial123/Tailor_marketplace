# Tailor & co.Stitch — static starter

This is a static HTML/CSS/JavaScript starter that works on GitHub Pages without Node.js or a build step.

## Publish with GitHub Pages
1. Upload `index.html`, `styles.css`, and `app.js` to the repository root.
2. In Settings → Pages, select Deploy from a branch, branch `main`, folder `/ (root)`, then Save.
3. Wait for the Pages deployment to finish.

## Important
- Tailor cards are demonstration examples, not verified businesses. Replace them with real listings and get permission before publishing contact details.
- The registration form currently opens the visitor's email app; it does not create an online account.
- Supabase authentication, database listings, image uploads, maps, payments and chatbot are not connected yet. They require separate setup.
- Do not publish secret keys. A Supabase service role key must never be placed in browser code.
